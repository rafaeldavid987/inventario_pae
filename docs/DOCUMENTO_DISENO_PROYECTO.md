# SISTEMA DE INVENTARIO PAE

## Información del proyecto

**Nombre:**
Sistema de Inventario y Administración PAE

**Framework**
Laravel 13

**PHP**
8.5

**Base de datos**
MySQL

**Frontend**
Blade + Bootstrap 5

**Control de versiones**
Git + GitHub

---

# Objetivo

Desarrollar un sistema web para administrar el inventario del Programa de Alimentación Escolar (PAE), permitiendo controlar productos, compras, inventario, minutas, despachos y reportes.
